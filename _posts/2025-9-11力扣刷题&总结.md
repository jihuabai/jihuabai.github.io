### 回溯
- [433](https://leetcode.cn/problems/minimum-genetic-mutation/)
#### 题解
    看到一个比较有意思的解法，这道题可以采用回溯来解决，正常思路都是从start开始搜索，然后以每一个字符串为顶点进行深搜，
搜索方向则以题目中规定的:每个字符串只能以A 、C、G、T中的一个字符进行变异，然后根据变异后的字符串是否在bank中来决定
搜索截止条件。
    但是还有一种做法是根据bank来反向匹配start。思路是:从bank中每一个字符串出发，判断其是否与start只差一个字符，如果是
则证明可以通过一次变异从start变异到该字符串，然后以该字符串为新的start继续进行搜索，直到搜索到end为止。
    这种做法的好处是:不需要考虑每个字符变异成A、C、G、T的情况，只需要判断bank中每个字符串与start的差异即可。
    代码如下:
``` java
class Solution {

    int ans = Integer.MAX_VALUE;
    
    public int minMutation(String startGene, String endGene, String[] bank) {
        List<String> bankList = List.of(bank);
        dfs(startGene,endGene,bankList,new boolean[bank.length],0);
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }

    public void dfs(String startGene, String endGene, List<String> bank,boolean[] used, int t) {
        if (t > ans) {
            return;
        }
        // 超过截止条件还不相等，说明不存在这样的路径
        if (startGene.equals(endGene)) {
            ans = Math.min(ans, t);
            return;
        }

        for (int i = 0,diff = 0;i < bank.size();i++,diff = 0){
            if (used[i]){
                continue;
            }

            // 计算是否一次变异
            for (int j = 0;j < 8;j++){
                diff += startGene.charAt(j) != bank.get(i).charAt(j) ? 1 : 0;
            }

            // 如果一次变异得到，则进行下一次搜索
            if (diff == 1){
                used[i] = true;
                dfs(bank.get(i),endGene,bank,used, t + 1);
                used[i] = false;
            }
        }
    }
}
```

### 拓扑
- [210](https://leetcode.cn/problems/course-schedule-ii/)
- [207](https://leetcode.cn/problems/course-schedule/)
#### 题解
    这两道题都是典型的拓扑排序问题，210题是要求出拓扑排序的结果，而207题是要求判断是否存在拓扑排序。
    这两道题的思路都是一样的，首先根据输入的边建邻接表，然后计算每个节点的入度，最后进行拓扑排序。
    拓扑排序的过程是:首先将所有入度为0的节点入队，然后不断出队节点，并将其邻接节点的入度减1，如果邻接节点的入度减1后为0，则将其入队。
    最后如果出队的节点数等于节点总数，则说明存在拓扑排序，否则不存在。
    代码如下:
``` java
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        int[] inDegree = new int[numCourses];
        Map<Integer, List<Integer>> map = new HashMap<>();

        for (int i = 0; i < prerequisites.length; i++) {
            int[] course = prerequisites[i];
            inDegree[course[0]]++;
            // 存放的依赖关系，比如[1,0],0课程依赖的是1，1的前置课程是0
            map.putIfAbsent(course[1],new ArrayList<>());
            map.get(course[1]).add(course[0]);
        }

        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0;i < inDegree.length;i++){
            if (inDegree[i] == 0){
                queue.offer(i);
            }
        }

        while (!queue.isEmpty()){
            int course = queue.poll();
            numCourses--;
            for (int rely : map.getOrDefault(course,new ArrayList<>())){
                inDegree[rely]--;
                if (inDegree[rely] == 0){
                    queue.offer(rely);
                }
            }
        }
        
        return numCourses == 0;
    }
```
当然还有另一种思路: 就是通过深度搜索的方式进行路径检索，同时基于已经存在的路径作回环检测。代码如下:
``` java
    public boolean isLoop = true;
    
    public boolean canFinish(int numCourses, int[][] prerequisites) {
                List<List<Integer>> graph = new ArrayList<>();
        int[]               status = new int[numCourses];
        for (int i = 0;i < numCourses;i++){
            graph.add(new ArrayList<>());
        }

        for (int[] pre : prerequisites){
            graph.get(pre[0]).add(pre[1]);
        }

        for (int i = 0;i < numCourses;i++){
            dfs(i,graph,status);
            if (!isLoop){
                return false;
            }
        }

        return isLoop;
    }

        public void dfs(int source, List<List<Integer>> graph,int[] status){
        if (!isLoop){
            return;
        }

        if (status[source] == -1){
            isLoop = false;
            return;
        }

        if (status[source] == 1){
            return;
        }

        status[source] = - 1;
        for (int rely : graph.get(source)){
            dfs(rely,graph,status);
        }
        status[source] = 1;
    }
```
